# One-minute live demo

Record the real running app; do not use a mockup. Use a test venue name and disposable passwords. Do not show API keys, private venue data, or real guest accounts.

## Prepare

On the venue computer, run `npm ci`, `npm run build`, and `npm start`. Sign in at `http://127.0.0.1:3000/admin`, change the fresh-install owner password, create a test community, select a venue type, and enable Shared Feed and Noteboard. Connect a guest phone or a second browser to the same private Wi-Fi. Enable guest hosting and keep the generated join URL or QR code visible.

## Record

| Time | Show |
| --- | --- |
| 0:00–0:08 | Name Locomi and the problem: guests at a physical venue can join a short-lived community over the venue's Wi-Fi. |
| 0:08–0:18 | Show the owner creating a venue community and choosing its venue type and feature modules. |
| 0:18–0:25 | Enable guest hosting and show the generated QR code and join URL. |
| 0:25–0:42 | Scan the QR code on a second device; publish one Shared Feed post and one Noteboard note. Keep both devices visible if possible. |
| 0:42–0:52 | Return to loopback-only owner moderation and show the contributions arriving in the real app. |
| 0:52–1:00 | Close by showing the project README's setup command and pointing contributors to `CONTRIBUTING.md`. |

Keep the recording under one minute, use readable text and cursor movements, and include captions or narration. Avoid showing password entry or configuration secrets.
